# Tonkotsu ramen — tall noodle pull

Entry for make.fun food-picture-01: a photorealistic tonkotsu ramen shot
built to win the judge's hunger test — a dramatic tall glossy noodle pull
lifted by chopsticks, a jammy egg with dripping yolk, a chili-oil spiral
on creamy broth, torched chashu, and rising steam on a dark slate table
under warm cinematic light.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` (1024x1024 JPEG, 232,734 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
